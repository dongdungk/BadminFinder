# 🏸 BadminFinder: 스포츠 시설 정보 및 커뮤니티 플랫폼

BadminFinder는 위치 기반 서비스와 사용자 참여(Crowdsourcing)를 결합하여 공공 체육 시설 정보를 실시간으로 제공하고, 사용자 간의 활발한 커뮤니티 활동을 지원하는 Flutter 기반의 모바일 애플리케이션입니다.

## 🚀 프로젝트 개요 및 기술 스택

| 구분 | 내용 |
| :--- | :--- |
| **주요 목표** | 공공 체육 시설에 대한 정확한 정보 제공, 위치 기반 현장 태깅 및 리뷰 기능, 통합 커뮤니티 구축. |
| **개발 언어** | Dart |
| **프론트엔드/프레임워크** | Flutter |
| **상태 관리/아키텍처** | Provider, MVVM (Model-View-ViewModel) |
| **핵심 백엔드/DB** | Firebase (Authentication, Firestore) |
| **주요 외부 API** | 서울시 공공체육시설 API, Google Maps API |

## 💻 프로젝트 기능 상세 및 구현 내용

### 1. 라우팅, 아키텍처 및 네비게이션 구조 (담당: 김동영, 김태호, 양석주)

본 프로젝트는 MVVM과 GoRouter를 통합하여 효율적인 구조를 구축했습니다.

* **MVVM 아키텍처 (김동영, 김태호, 양석주):** 데이터(`Model`), 비즈니스 로직(`ViewModel`), UI(`View`)를 분리하여 코드의 유지보수성을 극대화했습니다.
* **통합 라우팅 시스템 (김동영, 김태호, 양석주):** 모든 화면 이동 및 탭 전환을 **`go_router`** 기반으로 관리하며, 네비게이션 구조를 명확하게 설계했습니다.
* **`StatefulShellRoute` 적용 (양석주):** 커뮤니티 내부 페이지 이동 시 하단 탭의 상태를 유지하는 기능을 적용하여 사용자 경험을 향상시켰습니다.
* **데이터 전달 최적화 (팀 공동):** `GoRouter`의 `state.extra`를 활용하여 **객체 데이터(예: PostModel, ReviewModel)**를 직접 전달함으로써, ViewModel의 데이터 로딩 의존성을 최소화했습니다.

| 주요 라우팅 경로 | 담당자 연관 | 연관 기능 및 데이터 흐름 강조 |
| :--- | :--- | :--- |
| **`/login`** | 김동영 | 인증 시작점: Firebase Auth 스트림 연동, 로그인 상태에 따른 화면 전환 관리. |
| **`/facility/:id`** | 김동영 | 시설 상세: 위치 기반 서비스의 핵심 화면으로, 시설 ID 기반 상세 정보 및 지도 기능 연동. |
| **`/community/post/:id`** | 양석주 | 게시글 상세: `state.extra`로 PostModel을 전달받아 조회수 증가 로직 실행 및 상세 내용 렌더링. |
| **`/news`, `/stats`** | 김태호 | 뉴스 및 통계: 외부 API 및 `fl_chart` 기반 데이터 시각화 결과 제공. |
